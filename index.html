Про веб-застосунок PostService

Назва: Система обліку поштових відправлень

Версія: 1.0 (клієнтський веб-модуль)

Призначення: Реєстрація, перегляд, редагування та видалення записів поштових посилок через REST API PostService.

Технології

  • HTML5 — розмітка структури сторінок;
  • CSS3 — стилізація та адаптивний інтерфейс;
  • JavaScript (ES6+) — логіка роботи SPA, робота з DOM;
  • Fetch API + async/await — асинхронна взаємодія з REST API;
  • localStorage — локальний резервний режим при відсутності сервера.

Правила перевірки даних

  • Поля «Відправник» та «Одержувач» є обов'язковими (мінімум 2 символи);
  • Поле «Опис вмісту» є обов'язковим;
  • Вага та всі три розміри (Д×Ш×В) мають бути строго більшими за нуль;
  • Оголошена цінність та вартість доставки не можуть бути від'ємними.
